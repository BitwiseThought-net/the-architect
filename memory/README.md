# memory/ - LLM handoff notes

Read these in order before doing any work in this repo. They are written for an
LLM picking up where the last session stopped.

1. `project-overview.md` - what the repo is and how it is laid out.
2. `progress.md` - what has been done, what is untested, what to do next.
3. `decisions.md` - design choices and the reasons, so they are not relitigated.

Rules: update `progress.md` at the end of every session; keep notes factual;
never put secrets in this folder; docs in `docs/` use hyphens, not em dashes.
